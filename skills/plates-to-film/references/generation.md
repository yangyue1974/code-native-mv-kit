# 自动生成素材：plates 流水线

图片用 **image2**（OpenRouter 上的 `openai/gpt-image-2`），视频用**可灵**（官方命令行工具 `kling`，以选定的图为首帧）。
两者由 `scripts/plates.py` 串起来：镜头表 → 候选 → 联系表 → 选定 → 成品（P01.png / V01.mp4）→ `ingest.sh`。
用户也可以自己手动生成、把文件丢进素材文件夹，流水线不是唯一入口。

## 安装（一次）

```bash
bash ~/.claude/skills/plates-to-film/scripts/install_plates.sh
```

- **OpenRouter key**：用户在 OpenRouter 的 Keys 页面新建并复制 key，告诉你“复制好了”，你运行 `plates setkey`。
  它从剪贴板写入 `~/.config/plate-pipeline/openrouter.key`（权限 600）并清空剪贴板。
  绝不让用户把 key 贴进对话，绝不打印、读取或复述 key 文件内容。
  验证用 `GET https://openrouter.ai/api/v1/key` 与 `/credits`，只报额度和余额。
- **可灵**：先问账号是国内站（klingai.com）还是海外站，装对应的包（`@klingai/cli-cn` 或 `@klingai/cli-global`），
  再运行 `kling login`，由用户在浏览器里授权。之后按官方 kling-cli 技能的规则使用：
  - 模型和参数以 `kling who_am_i` 为准；
  - 每次提交都扣灵感值，而且不能取消；
  - 结果链接 24 小时后失效，要立即下载；
  - 会员才能拿到无水印版本（`urlWithoutWatermark`）。

## 镜头表 shots.toml

`plates init` 生成模板。要点：

- `[project]`：
  - `style`：统一风格段，自动加在每条图片提示词前面。
  - `character`：女主角描述。
  - `character_refs`：定妆照，可以是文件路径，也可以是已选定镜头的 id。
  - 镜头设了 `character = true`，就自动带上 character 描述和定妆照参考图。
- `[defaults.image]`：`model`、`aspect`、`quality`（low / medium / high）、`n`（每个镜头出几张候选）。
- `[defaults.video]`：`model`、`duration`、`resolution`、`n`。
- `[[shot]]`：
  - `id`、`kind`（image 或 video）、`note`（对应哪句歌词、做什么用）、`prompt`。
  - 可选 `refs`（额外参考图）。
  - 视频镜头用 `from` 指定首帧取自哪个镜头；可选 `tail` 指定尾帧，只有支持尾帧的模型能用。

## 流程和纪律

1. `plates plan`：列出数量和预算。**把预算报给用户，拿到同意再花钱**。
   单价会随账本（ledger.jsonl）里的实际花费自动更新。
2. `plates images --yes`：并行生成，每个镜头自动拼一张联系表 `review/<id>.jpg`（候选编号印在图上）。
3. **你来筛选并选定**（用户已明确要这样）。逐张检查：
   - 机位对不对
   - 人物是不是同一个人
   - 动作对不对
   - 有没有穿模、手指异常、多余文字
   
   然后 `plates pick P03=2`，并在汇报里写清楚选了哪张、为什么，淘汰的几张各有什么问题。
   只有几张在审美上确实不分高下时，才请用户选。
4. `plates videos --yes`：以选定的图为首帧生成视频，自动下载无水印版，并拼一条 4 帧缩略条。
   视频要**逐帧看**（每秒 3 帧左右拼成联系表），重点查穿模、形变、闪烁。选定用 `plates pick V02=1`。
5. 成品目录（默认 `sucai/`）交给 `ingest.sh`，之后回到主流程。
6. 花钱命令不加 `--yes` 只预览。失败不要自动重投：把原因告诉用户，问是重试、改提示词还是放弃。

## 已实测的数据（2026-09-29）

| 引擎 | 规格 | 单价 | 速度 | 表现 |
|---|---|---|---|---|
| image2（OpenRouter）| 16:9 固定 1536×864，medium | 约 $0.044 / 张 | 3 张约 34 秒 | 复杂语义照做，机位、动作、人物都对；定妆照参考很稳。**主力画图** |
| 可灵图片 3.0 Omni | 2K 约 2720×1536 | 2 灵感值 / 张 | 约 1 到 3 分钟 | 画质好但不听话：长提示词里的机位、动作、人种容易丢，会冒出文字。只在要大尺寸、要大量抽卡时用 |
| 可灵视频 4.0 Flash | 720p，3 到 20 秒，只收首帧 | 约 6 灵感值 / 秒 | 5 秒约 1 到 2 分钟 | 车和运镜很稳；人物加光效容易穿模 |

会员还能用 1080p（3.0 系列能出 4K）、一次出 4 条视频、首尾帧（2.5、2.6、3.0），
以及“全能参考视频”（omni_ref_video，把图、视频、主体混在一起当参考）。

## 提示词写法

- **给 image2**：可以长、可以复杂。统一设定照写，逐条列要求它都会落实。
  有歧义的名词要写死，例如“车内中央后视镜，挂在挡风玻璃上方”。
- **给可灵视频**：
  - 只写运动和机位，一句只说一件事，第一句写“机位固定不动”或具体的运镜方式。
  - 不要写“光从脸上划过”这类会动的光效，会被理解成物体从人脸前穿过（实测穿模）。
    要写光，就写成皮肤上的明暗变化。
  - 动作的快慢要写出来：“慢慢眨眼”会变成闭眼两秒，想要干脆的眨眼就写“快速眨一下眼”。
  - 大动态镜头（车、城市、镜头运动）是强项，优先交给它。
- **测试档位**：测试一律用最便宜的档（720p、最短时长、medium 画质），正式片再升级。
  用户选 480p 或 720p 是出于成本考虑，不是工具做不到，不要当成缺陷来描述。
