# 涂层：盖掉塑料感的那一层

涂层是一个全屏片元着色器，对最终画面逐像素处理。它的任务是**把画面放进一种真实介质里**，
并且**跟着音乐呼吸**：各项强度由底鼓和切点驱动，不是静态滤镜。

两套成品配方都在示例代码里，可以直接抄：
- 印刷涂层：`assets/examples/night-plus/nightplus.js` 里的 `COAT_FS`
- 银盐涂层：`assets/examples/case-0214/casefile.js` 里的 `COAT`

## 分层原则

```
底片层（素材/桌面，画在渲染目标或 Canvas2D 上）
   ↓ 涂层着色器：错位 → 调色 → 介质纹理 → 边缘 → 光晕 → 颗粒 → 暗角 → 闪光
图形层（Canvas2D：文字、界面、手写、印章）在涂层之后叠上去
```

**图形一定要在涂层之后叠。** 这样红笔和红章才能保持纯红、清晰，
看起来像是“画在照片上”，而不是“照片里本来就有”。
NIGHT+ 给图形层也加了一点点错位（`uGfxMis`），让它和网点属于同一种印刷。
案卷则完全不处理图形层，因为手写本来就在相纸表面。

## 配方一：印刷网点（NIGHT+）

- **套色错位**：R、G、B 分别沿一个方向偏移 `uMis` 像素，平时 1.6，底鼓时加到约 12；出故障镜头时再加 26，并迅速衰减。
- **调色**：饱和度乘 1.28，暗部压到墨蓝，亮部偏暖。结尾“早晨”那段整体提亮、变冷。
- **CMY 半色调**：三块加了旋转角度的网屏（15°、75°、0°），网点半径等于 sqrt(油墨量)×0.62。
  只混进中间调和亮部，混合比 `uHalf` 平时 0.26、底鼓时 0.6；网格大小 `uCell` 在 5.5 到 8.5 之间随底鼓变化。
- **墨线**：用 Sobel 算子求边缘，按 `uInk=0.32` 压暗，像印刷的描边。
- **光晕**：最亮的地方向外渗一圈红橙色。
- **颗粒 + 暗角**，然后叠图形层，最后是闪色：切点处 2 到 3 帧，颜色可选洋红、红、白。

`hitAt(v)` 的写法：取底鼓的 exp(-7·dt)，和镜头起点的 0.6·exp(-9·dt)，两者取较大值。
所有“呼吸”都从这个值来。

## 配方二：银盐 + 单色保留（案卷）

- **片门晃动**：每帧整体随机偏移 1 到 2 像素。
- **银盐曲线**：先转成亮度，再用 smoothstep 加 pow(1.18) 压出深黑；映射到从近黑到奶白（0.95, 0.92, 0.84）的色阶上。
- **单色保留**：按**色相**判断，不能用“R 减 G”这种差值判断。
  用差值判断会把钠灯的琥珀色也保留下来，满屏都是橙色。
  - 红色：饱和度大于约 0.5，并且色相离 0° 小于 12 到 22°。
  - 蓝色：色相在 222° 上下 18 到 34° 以内。
  - `uKeep` 在“城市变蓝”那个词上从红切到蓝。
  - `uBlueWide` 让这一句里蓝色的门槛临时放宽，于是整座城一下子从黑白里透出蓝来。唱完再收回。
- **结尾全彩**：`uColor` 用 2.8 秒从 0 升到 1，画面回到原图颜色，这就是情绪释放点。
- **监控模式** `uCctv`：扫描线加一点偏冷的色调，只在监控镜头上开。
- **颗粒按 24fps 跳**（`floor(v*24)`）：两种尺度的银盐颗粒，暗部多一点墨粉斑点，灰尘亮点每 2 帧换一次，偶尔出现一道竖直划痕。
- **烧边暗角**，然后是闪光灯：接近白色，再加一点溢出。

## 设计新涂层

先问“这个类型的画面本来印在什么介质上”，再从这个介质的物理缺陷里找参数：

| 介质 | 可以做的 |
|---|---|
| 旧报纸 | 单色粗网点、纸纹、油墨透印（背面文字镜像淡出） |
| 录像带 | 色度溢出、跟踪条、磁头噪声带，暂停时画面抖动 |
| 热敏打印 / 传真 | 1 位抖动、横向拉丝、纸卷边 |
| 丝网印刷海报 | 2 到 3 个专色、套色偏移、颜料堆积 |
| 游戏机 CRT | 像素栅格、荧光粉三色条、弧形暗角、扫描闪烁 |
| 复印件 | 高对比、边缘黑框、碳粉斑、逐次复印的劣化 |

每个涂层都要有：
1. 至少一个随底鼓变化的参数。
2. 一个贯穿全片的“叙事参数”，比如黑夜时钟、单色保留、恢复全彩，用它来画出情绪弧线。
3. 一个结尾释放。

## 验收

- 放大到 2 倍看局部：网点或颗粒肉眼可见，但人脸依然可读。
- 联系表里整体不压抑，亮部够亮。用户对“压抑”很敏感。
- 单色保留有没有漏色：钠灯、皮肤、夜空的藏青色。
- 成片码率：颗粒和网点让每帧都很“贵”，30 秒原片有 300 多 MB，正常。发给用户用 CRF 20 的预览版。
