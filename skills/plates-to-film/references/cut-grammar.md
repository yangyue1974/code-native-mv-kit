# 剪辑语法和两种引擎

## 先写节拍表

把 `segment_timing.py` 的输出变成一张表，再写代码：

```
片内时间  歌词/事件            画面                     转场        图形
0.00     Just                 V01 车灯（监控）          闪白        片名打字 CASE FILE / 0214
0.66     drive                P06 隧道                  硬切        红圈 + 手写“无牌黑色轿跑”
1.67     Like we still got…   桌面：P02 / P13 / P14      落桌×3      笔录卡打字，路线红线
...
```

对位规则（按优先级）：
1. **钩子词的起点**：如 "Just drive"、"blue"、"lie"、"Tonight"，一定要有一个动作，比如切、盖章、切色。
2. **强拍**：换段落，大元素落下。
3. **底鼓**：涂层呼吸，桌面震动，卖点卡跳入。
4. **普通拍**：照片落桌、圈注一笔、连闪的一格。

节奏密度：主歌的尾巴和第一句松一点，第二个 "Just drive" 开始连闪（半拍一格），
最后的长音 "Tonight" 给一个 3 到 5 秒的整镜头，用来收情绪。
**快但不能乱**：每一刀都要能说出它落在哪个词或哪个拍上。

## 引擎 A：镜头引擎（`nightplus.js`）

每个镜头就是镜头表里的一行：

```js
{ t0: 2.94, src: "P13", m: mv(1.0, 1.55, 0.1, 0.17, -0.02, -0.06, "expo"), tr: "zoom" }
// src：P 开头是图片，V 开头是视频（配 from 起点秒、rate 速度，负数就是倒放），END 是结束卡
// mv(z0,z1, x0,x1, y0,y1, 缓动, r0,r1)：镜头内的推拉摇（图像 UV 坐标）
// tr：flash | whipLeft | whipUp | zoom | slice | dissolve | cut，可附加 flash: 颜色、glitch: 1
```

- 底片着色器 `PLATE_FS` 负责缩放、平移、旋转，并**按速度做运动模糊**：沿平移方向 14 次采样，加上沿缩放方向的径向模糊。
  甩镜头因此有真实的拖影。
- 甩镜头会跨两个镜头：下一镜的甩，在上一镜的最后 0.14 秒就开始。
- 切条（slice）：22 条横带各自在不同时刻翻到下一镜，同时被横向推一下。
- `toScreen(sh, v, px, py)`：把图像 UV 换算成屏幕坐标。界面、标注可以借此**粘在画面里的屏幕上**，镜头推拉时也跟着走。
  屏幕四角在收素材时就量好。
- 视频：只预载镜头实际用到的帧，并把它们换进每段视频唯一的一张纹理里。帧号由 `frameOf` 算出，上限按 `manifest.json` 设。

## 引擎 B：桌面引擎（`casefile.js`）

每一帧先用 Canvas2D 摆好“底片”，上传成纹理，再过涂层；然后把第二张 Canvas2D（手绘层）盖在上面。

- 段落表 `SEG` 的每一项对应 `DRAW` 里的一个函数：`DRAW[id](v, s)` 画底片层和手绘层，
  返回这一段的涂层参数（cctv、flash、color）。
- `deskCam(ctx, c)`：桌面世界坐标到屏幕的变换。底片层和手绘层要用**同一个**相机，红圈才能对准照片。
- `kickCam(c, v)`：每一拍桌面“咚”一下，放大 2.5%，同时轻微位移和旋转。静止的照片因此也在打拍子。
- `print(...)`：照片带白边，有落下的回弹（back 缓动），阴影从远到近，最后停在一个随机的小角度上。可以加证物标签。
- `card(...)`：带横线的卡片，文字按字符在指定时间段里逐个打出来。
- `stamp(...)`：先放大再砸下，边框加字，再用 destination-out 打出油墨磨损的斑点。
- `loop(...)` 和 `stroke(...)`：红笔圈和线，笔迹带随机抖动，**按进度实时画出来**。
- `hand(...)`：马克笔字，逐字出现。
- `osd(...)`：监控屏显，包括机位、地点、会走的时间码、闪烁的 REC。
- `transcript(...)`：歌词变成笔录字幕条 `S-07: "..."`，逐词出现。
  如果画面上已经有打字卡写着同一句，就关掉它，别重复。
- `cover(ctx, img, z, px, py, pixel)`：整屏铺满，`pixel>1` 时先缩小再用最近邻放大，做“放大”那种马赛克效果。

**构图检查点**（这些都踩过）：
- 桌面镜头的缩放不要低于 0.95，否则空桌面太多，照片太小。
- 手写字和结尾卡的位置要按**镜头最后一刻**的相机算，不然会出画。
- 印章不能被后画的涂黑条压住。涂黑条只盖时间或名字这类“信息”。
- 放大的准星要先算出目标（比如眼睛）在原图里的 UV，再用 `px`、`py` 把它移到画面中心，这样三级放大才会始终对准。

## 手法清单（按类型挑）

- **转场**：闪白或闪色 2 到 3 帧、甩镜头加拖影、急推、切条、叠化（只用在最后的长音）、照片落桌、快门闪光、三级放大、故障错位。
- **图形**：打字机、逐词歌词、卖点卡、价格卡、贴在屏幕上的界面、弹窗被划走、计数器、行动按钮加鼠标、印章、红笔圈注、红线连接、证物标签、监控屏显、涂黑条、测谎曲线、法律小字滚动、结束卡。
- **把音乐数据画成图**：测谎曲线用的是 `SONG.rms`（歌曲本身的响度），"lie" 那个词上再加一个尖峰。
  类似的还有：K 线、心电图、雷达扫描、磁带电平表。这是代码片独有的“真实”。
