# 概念手册

## 什么样的概念能成

两部被认可的片子，都是把“一首情歌的副歌”放进了一个**和情歌无关、但有强烈视觉语法的类型**里：

| | NIGHT+ 黑夜续费服务 | 案卷 0214 |
|---|---|---|
| 类型 | 讽刺豪车/订阅广告 | 黑色侦探片的证物档案 |
| 一句话 | 一家公司卖“黑夜续费”，让凌晨两点永远不结束；最后付款失败，太阳照常升起 | 她是 7 号当事人，所有画面都是证物，歌词成了笔录；最后一次被看到是凌晨 5:46 的楼顶，悬案 |
| 歌词的角色 | 广告语/卖点（“Like we still got all night” 变成“无限黑夜”） | 当事人的陈述（S-07: "..."），“lie” 被盖上“未证实” |
| 图形语言 | 品牌字、卖点卡、价格、界面贴到手机/中控/仪表屏、弹窗被划走、续费按钮、付款失败章、法律小字 | 监控屏显（机位、时间码、REC）、打字机笔录、红笔圈注和手写、证物标签、印章、涂黑条、测谎曲线、红线证物墙、底片联系表 |
| 结尾反转 | 付款被拒，日出 | 日出时画面恢复全彩，盖章“悬案” |

共同点：
- **歌词被“挪用”**，变成另一个类型里的文本，就产生了幽默或悬疑。
- **有一个贯穿的小道具**：黑夜时钟、单色保留、证物编号。
- **结尾是这个类型自己的收尾动作**：付款失败、结案盖章，而不是淡出。
- **概念要能直接“看出来”**：第一秒就要让人知道这是广告或案卷（片名打字、品牌字、监控屏显）。

## 类型库（没用过的候选）

每个都自带图形语言，都能用同一批“夜、车、城市、她”的素材：

- **老电影预告片**：分级卡、“今夏”式大字、演职员滚动、胶片划痕、声画错位字幕。
- **天气预报/交通广播**：地图、等压线、城市温度卡、“蓝色预警：天将亮”，播报员的屏幕里放素材。
- **游戏读档**：存档槽截图、HP 条、任务日志、“存档于 02:14”、选项菜单，结尾“GAME OVER / 继续？”。
- **博物馆藏品图录**：展品编号、标本卡、测量尺、玻璃罩反光，“凌晨两点，某城，年代不详”。
- **股市行情/财报**：K 线跟着歌曲音量走，“黑夜指数”，涨停/熔断，日出时收盘。
- **航空安全须知卡**：线描风、步骤编号、禁止图标，“请系好安全带，直到城市变蓝”。
- **自然纪录片**：拉丁学名标签、观察日志、测距框、“夜行动物”。
- **失物招领/寻人启事**：复印纸、撕条、胶带、手写电话号码。
- **报纸号外/杂志封面**：大标题、分栏、网点照片，每拍翻一版。

挑选标准：图形语言够独特、能和歌词形成反差、用户没见过、素材撑得住。

## 同素材再剪一部：全维度不同矩阵

第二部要让人觉得是另一部片子，下面每一行都必须和上一部不一样：

| 维度 | NIGHT+ | 案卷 0214 |
|---|---|---|
| 歌曲段落 | 第一段副歌 52.9–82.9 | 最后一段副歌 152.9–182.9 |
| 类型/基调 | 广告，讽刺，明亮 | 侦探，悬疑，冷 |
| 涂层 | CMY 印刷网点 + 套色错位 + 高饱和 | 黑白银盐 + 颗粒灰尘划痕 + 只留一种颜色 |
| 颜色策略 | 满屏霓虹洋红和钴蓝 | 红 → 蓝 → 日出全彩 |
| 画面单位 | 整屏素材 | 照片是“物件”，落在桌上 |
| 转场 | 甩镜头、急推、切条、闪色 | 照片落桌、快门闪光、放大三级跳 |
| 图形 | 屏幕界面、卖点卡 | 手写、印章、打字、监控屏显 |
| 字体 | Michroma、Newsreader 斜体、Big Shoulders | Courier Prime、Permanent Marker、VT323 |
| 帧的气质 | 30fps 数字感 | 颗粒按 24fps 跳，像胶片 |
| 结尾 | 付款失败 + 日出 | 日出恢复全彩 + 悬案章 + 结案页 |

同一张图在两部里的用法也要不同。比如她的眼睛：广告里是节拍连跳的特写；案卷里是三级马赛克放大，“是她”。

## 被否掉的方向（别再走）

- **照片写实 + 视差，窗外加光效**：“素材非常死板”，“方向也不对”。补光修不了死板。
- **扫描/点云/线框实验室风**：没打动人。
- **用代码建一座剪纸城市**：“非常难看”。代码造的世界比不过生成图。
- **情侣开车的剧情**：“太俗套”。概念要“更飞”。
- **长时间一个人在车里开车的画面**：用户明确不要，要有镜头调度和快速转场。
- **规律重复的节奏**（第一部 MV 的吃豆人）：要有“强视觉冲击”、不循规蹈矩的画面。
- **饱和度低、压抑**：要提饱和度。案卷的黑白之所以成立，是靠红和蓝的点睛，加上日出的全彩释放。
- **看起来像 AI 竖屏短剧**：塑料感没处理、转场慢、构图居中呆板。用户要的是“广告大片”。

## 用户的口味（已确认）

- 要“wow”，要跟看过的 AI 视频都不一样。参考片是 YouTube 上的 “SLOPCORE: ESCAPE VELOCITY”：
  大量生成画面打底，上面叠代码做的动态设计。
- 第一次做这类片子时会把创意交给你：别问开放式问题，带着理由拍板，用画面给他看。
- 反馈很短，一两句。每轮都给看得见的东西。
- 只用中文沟通。
